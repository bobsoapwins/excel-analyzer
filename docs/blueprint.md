# **App Name**: Excel Insights

## Core Features:

- File Upload: Upload an Excel file via a drag-and-drop interface or a file selection dialog.
- Data Display: Display the column names and their corresponding percentage values in a tabular format. 
- File Parsing: Parse the uploaded Excel file (in formats such as .xls or .xlsx) and extract the data for processing. Use appropriate libraries or methods to handle different Excel file formats.
- Percentage Calculation: Calculate percentage values for each column, handling various data types (numeric, text, etc.) appropriately.

## Style Guidelines:

- Primary color: Calm blue (#5DADE2) to inspire trust and clarity.
- Background color: Light gray (#F0F4F7) to reduce eye strain and ensure readability.
- Accent color: Soft orange (#E59866) to highlight important actions such as download and upload, creating a smooth, harmonious contrast with the blue tones and enhancing the user experience.
- Clean and professional sans-serif font.
- Simple and intuitive icons for actions like upload, download, and settings.
- Use a clear, tabular layout to present the data.
- Subtle animations for loading and data updates.
